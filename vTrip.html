🚴 Маршрут

моя позиція
—
не задано (довгий тап по карті)
Довгий тап по карті → «Фініш», «Через» або «Старт». Маршрут будується через OpenRouteService (велопрофіль), запасний варіант — TomTom.

    📍 Заклади

    Точки беруться зі спільної бази VRacer (Налаштування → Сигнали → бренд-бази). Показуються поблизу центру карти від зуму 13.

    🚆 Транспорт · TDX

    —
    YouBike на карті
    Кнопка 🚲 праворуч вмикає станції. Показуються від зуму 14.
    🚆 Потяги TRA (звичайні й локальні)
    Кнопка «МТ» → «Потяг» праворуч показує станції (від зуму 11). Тап по станції — розклад до кінця дня; тап по поїзду в розкладі — лінія його маршруту. «Поїздка» переносить станцію сюди.
    🚌 Автобуси
    Кнопка «МТ» → «Автобус» показує зупинки навколо центру карти (від зуму 15). Тап по зупинці — прибуття; тап по маршруту — його лінія. «Поїздка» переносить зупинку сюди.
    Список зупинок — із завантажених навколо карти: увімкніть 🚌 і наведіть карту на район (зум 15+).
    Тут буде: YouBike (станції й вільні велосипеди), автобуси, потяги (TRA/THSR), метро, комбіновані маршрути. Спершу перевіряємо ключі і доступність API з браузера.
